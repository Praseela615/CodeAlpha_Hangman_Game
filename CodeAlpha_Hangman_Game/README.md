# CodeAlpha Hangman Game

A beginner-friendly, text-based Hangman game created for the CodeAlpha Python Programming Internship task.

## Features
- Randomly selects one of 5 predefined words.
- Lets the player guess one letter at a time.
- Allows up to 6 incorrect guesses.
- Checks invalid and repeated guesses.
- Displays correctly guessed letters and incorrect letters.
- Offers the option to play again.

## Technologies and concepts
- Python 3
- `random` module
- Lists and strings
- Sets
- `while` loops
- `if/else` conditions
- Functions and user input

## Requirements
Python 3.8 or newer. No third-party packages are required.

## How to run
1. Download and extract the ZIP file.
2. Open the extracted `CodeAlpha_Hangman_Game` folder in VS Code, or open a terminal in that folder.
3. Run:

   ```bash
   python main.py
   ```

   On some Windows installations, use:

   ```bash
   py main.py
   ```

## How to play
- Enter one alphabet letter each turn.
- Correct guesses reveal letters in the word.
- You lose one attempt for each incorrect letter.
- You win by revealing the full word before making 6 incorrect guesses.
